# SA-nx

A native port of **Sonic Adventure** (Dreamcast) to PC and, later, Nintendo Switch homebrew,
built with [dream-recomp](https://github.com/phobos665/dream-recomp) static recompilation.

## Status

Early bring-up on PC. Nothing playable yet.

You need your own dump of the **PAL v1.003 (1999)** disc (MK-5100050) as a GDI with all three
tracks. No game data is in this repository.
